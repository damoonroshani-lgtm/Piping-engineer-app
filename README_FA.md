# پروژه اولیه Piping Engineer

این بسته شامل اسکلت اولیه رابط کاربری Flutter است.

## وضعیت فعلی
- رابط فارسی راست‌به‌چپ
- صفحه اصلی و بخش‌های آموزش، استانداردها، محاسبات و تجهیزات (فعلاً نمایشی)
- انتخاب تصویر نقشه از دوربین یا گالری

## مواردی که هنوز پیاده‌سازی نشده‌اند
- موتور OCR و تشخیص نمادها
- تحلیل هوش مصنوعی نقشه
- بانک اطلاعات کامل استانداردها
- محاسبات مهندسی کامل
- تنظیمات امنیتی و سرویس پشتیبان

## نکته
این بسته به‌تنهایی APK نیست. برای ساخت APK باید پروژه Flutter در محیط ساخت اندروید آماده و کامپایل شود.
